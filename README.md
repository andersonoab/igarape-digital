# Igarapé Digital

## Automação e Inteligência para RH

O **Igarapé Digital** reúne automações, auditorias, painéis e simuladores criados para resolver problemas reais de **Recursos Humanos, Departamento Pessoal e Payroll**.

O objetivo é transformar rotinas manuais, bases dispersas e conferências demoradas em processos mais simples, rastreáveis e orientados por dados.

> **Menos trabalho manual. Mais controle para RH e DP.**

## Acesse o site

Depois da publicação no GitHub Pages, substitua o endereço abaixo pela URL definitiva:

**https://andersonoab.github.io/igarape-digital/**

O site apresenta atualmente:

- **58 ferramentas catalogadas**;
- **10 áreas de atuação**;

- filtros por área, situação do projeto e disponibilidade de demo;
- dados fictícios e anonimizados em todas as demonstrações.

## Demonstrações interativas

As demos foram criadas para permitir que um potencial cliente compreenda a proposta da solução antes de uma implantação.

Entre as experiências disponíveis estão:

- localização de outliers e variações críticas na folha;
- conferência entre férias solicitadas e executadas;
- heatmap de variação mensal e explicação por rubrica;
- simulação de comissão, remuneração variável e rescisão;
- identificação de risco por dias consecutivos de trabalho;
- conciliação entre bases de benefícios;
- controle de CCTs e vencimentos;
- projeção de FTE e custo de pessoal;
- priorização de atividades de RH e DP;
- acompanhamento do fechamento da folha;
- organização visual do DP 360;
- classificação inteligente de arquivos;
- simulação de preenchimento de sistemas e SSA;
- consultas ao AskHR;
- organização diária de tarefas no Igarapé Daily Cockpit.

Todas as informações usadas nas demos são **fictícias**. Nenhum dado de colaborador, cliente ou empresa é enviado para servidores externos.

## Estrutura do repositório

```text
igarape-digital/
├── index.html
├── README.md
└── assets/
```

O arquivo principal do site deve ser chamado **`index.html`**. O GitHub Pages utiliza esse arquivo como página inicial.

## Como publicar no GitHub Pages

1. Crie um repositório chamado **`igarape-digital`**.
2. Renomeie o arquivo `portfolio-igarape.html` para **`index.html`**.
3. Envie `index.html` e `README.md` para a branch `main`.
4. Abra **Settings → Pages** no repositório.
5. Em **Build and deployment**, selecione a publicação pela branch.
6. Escolha a branch `main` e a pasta `/root`.
7. Salve e aguarde a geração do endereço.

A URL seguirá este padrão:

```text
https://andersonoab.github.io/igarape-digital/
```

Para uma URL gratuita sem o nome do projeto no final, o repositório deve ser chamado exatamente:

```text
SEU-USUARIO.github.io
```

Documentação oficial: [GitHub Pages](https://docs.github.com/pages/quickstart).

## Uso comercial

As demonstrações representam versões reduzidas das soluções. Uma implantação pode incluir:

- levantamento do processo atual;
- parametrização das regras da empresa;
- tratamento e padronização das bases;
- construção da automação ou painel;
- testes com dados controlados;
- documentação e treinamento dos usuários;
- acompanhamento após a implantação.

## Segurança e privacidade

- Não publique bases reais de folha, benefícios, ponto ou documentos pessoais no repositório.
- Não grave senhas, tokens ou credenciais dentro do HTML ou do código-fonte.
- Utilize somente dados fictícios nas demonstrações públicas.
- Ferramentas com informações sensíveis devem executar localmente ou em ambiente corporativo autorizado.
- Simulações fiscais e trabalhistas não substituem a validação técnica, jurídica ou o cálculo oficial da folha.
